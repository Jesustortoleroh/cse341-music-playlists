# 🎵 Music Playlists API

REST API to manage music playlists. CSE 341 Project - BYU-Idaho.

## 📋 Description

 Music Playlists API. It includes a working connection to MongoDB, GET and POST endpoints, and auto-generated Swagger documentation.

## 🚀 Technologies

- Node.js
- Express
- MongoDB + Mongoose
- Swagger (swagger-autogen + swagger-ui-express)
- dotenv
- CORS
